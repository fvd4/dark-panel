# ⚡ NovaPanel

پنل مدیریت VLESS دو مسیره (مستقیم ⚡ + ابری ☁️) با داشبورد فارسی، تم روشن/تاریک، ربات تلگرام و صفحه ساب عمومی — آماده دیپلوی روی Railway.

## ✨ ویژگی‌ها

- 🔗 هر کانفیگ = **۲ لینک VLESS** (مسیر مستقیم روی دامنه Railway + مسیر ابری روی دامنه شخصی/کلادفلر) برای فالبک خودکار در v2rayNG و NekoBox
- 🌐 ترنسپورت‌ها: `VLESS + WebSocket` و `XHTTP stream-up / packet-up`
- 🌓 تم روشن و تاریک + داشبورد فارسی راست‌چین با نمودار ترافیک ساعتی
- 📷 QR کد برای هر لینک، هر ساب و صفحه عمومی گروه
- 🗂 گروه‌های ساب: صفحه عمومی شیک (`/p/...`) برای مرورگر + لینک ساب متنی (`/sub-group/...`) برای اپ‌ها
- 📦 محدودیت حجم (KB/MB/GB)، 🚀 محدودیت سرعت (Mbps)، 👥 سقف آی‌پی هم‌زمان، 📅 انقضای روزی
- 🟢 اتصالات زنده، 📝 لاگ فعالیت‌ها و خطاها
- 🤖 ربات تلگرام مدیریتی (ساخت مرحله‌ای کانفیگ، لیست، فعال/غیرفعال، گروه‌ها، آمار)

## 🚀 دیپلوی روی Railway

1. این پوشه را در یک ریپوی گیت‌هاب بذار و Push کن:
   ```bash
   git init && git add . && git commit -m "NovaPanel v1" && git push
   ```
2. در [Railway](https://railway.com) → **New Project → Deploy from GitHub repo** → ریپو را انتخاب کن.
3. بعد از دیپلوی، از Settings → Networking یک **Public Domain** بساز.
4. **Volume** بساز و روی مسیر `/data` به سرویس وصل کن (تا کانفیگ‌ها با ری‌استارت نپرند).

## ⚙️ متغیرهای محیطی (Settings → Variables)

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `ADMIN_PASSWORD` | رمز ورود به داشبورد | `X4GKING` |
| `SECRET_KEY` | کلید سشن (اختیاری، خودکار ساخته می‌شود) | — |
| `DATA_DIR` | مسیر ذخیره وضعیت (Volume را همین‌جا وصل کن) | `/data` |
| `CDN_HOST` | دامنه ابری پیش‌فرض برای مسیر ☁️ همه کانفیگ‌ها | — |
| `DIRECT_HOST` | هاست دستی مسیر مستقیم (خالی = دامنه Railway) | — |
| `TELEGRAM_BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) | — |
| `TELEGRAM_ADMIN_IDS` | آیدی عددی ادمین‌ها با کاما، مثلاً `123,456` | — |

> **نکته مقاومت:** اگر دامنه شخصی داری، آن را روی کلادفلر بذار و در `CDN_HOST` بنویس.
> آن‌وقت مسیر ⚡ مستقیم به Railway وصل می‌شود و مسیر ☁️ از کلادفلر —
> اگر کلادفلر فیلتر شد، مسیر مستقیم کار می‌کند و برعکس. بدون دامنه شخصی هم
> هر دو مسیر روی دامنه Railway ولی با دو ترنسپورت متفاوت ساخته می‌شوند.

## 🤖 ربات تلگرام

1. `TELEGRAM_BOT_TOKEN` و `TELEGRAM_ADMIN_IDS` را ست کن و سرویس را Redeploy کن.
2. به ربات `/start` بده → ساخت کانفیگ، لیست، لینک‌ها، گروه‌ها و آمار.

## 📁 ساختار

| فایل | نقش |
|---|---|
| `main.py` | اپ FastAPI، احراز هویت، APIها، ساب، صفحات وب |
| `ui.py` | لاگین، داشبورد SPA، صفحه ساب عمومی |
| `links.py` | ساخت لینک VLESS دوگانه، کوتاها، گروه‌ها |
| `transport.py` | تونل WebSocket + XHTTP |
| `limits.py` | محدودیت سرعت Token Bucket |
| `state.py` | وضعیت مشترک، سشن، ذخیره روی دیسک |
| `bot.py` | ربات تلگرام |
